## 小專題題目:終極密碼
## 遊戲規則:
系統在指定範圍內隨機產生目標數字  
玩家持續猜測，每次猜測後範圍逐漸縮小  
直到猜中數字為止!
## 程式介紹:
## 玩法:
電腦隨機生成1\~100的目標數字(可自訂最大最小值)  
玩家需在目前遊戲的數值範圍(例:50\~70)內，猜一個數字  
若玩家猜的數字未命中，電腦將根據此玩家輸入的值更新下一回合的數值範圍  
當玩家猜中系統隨機生成的目標數字時  
遊戲結束
