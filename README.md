## 遊戲規則:
系統在指定範圍內隨機產生目標數字  
玩家持續猜測，每次猜測後範圍逐漸縮小  
直到猜中數字為止!

## 程式介紹:
### Game(控制)
負責遊戲主流程控制、回合管理與切換，並執行區間更新與勝負判斷。
### player(資料）
封裝玩家基本資料（名稱、ID)與遊戲狀態（猜測紀錄、狀態）。
### NumberGenerator(工具）
提供隨機數生成服務，確保目標值具均勻分布與不可預測性。
### Game Flow(流程）
負責整體遊戲流程控制，包括回合切換、管理與遊戲開始與結束條件判斷。

## 玩法:
電腦隨機生成1\~100的目標數字(可自訂最大最小值)  
玩家需在目前遊戲的數值範圍(例:50\~70)內，猜一個數字  
若玩家猜的數字未命中，電腦將根據此玩家輸入的值更新下一回合的數值範圍  
當玩家猜中系統隨機生成的目標數字時  
遊戲結束

## 程式如何安裝執行:
下載專案之程式碼和g++，並於任一可執行C++語言之編譯器編譯並執行
